# Adopters

Organizations and projects using telectl in production.

> telectl is actively developed and the maintainers would love to know who's
> using it. If you run it in production, open a discussion or a PR to add
> your organization here.

## How to add yourself

1. Open a [Discussion](https://github.com/ksauraj/telectl/discussions) or a
   Pull Request.
2. Add a row to the table below with your organization's name and, if you're
   comfortable sharing, a short note on how you use telectl.
